# The first wrong step

**Rule.** Repair a fault where the system first went astray. The place where it finally fell over is usually somewhere else.

**The question.** Is the input or state that set off the failure one the system is supposed to accept? If it is, the code that broke must cope with it. If it is not, something earlier let it through, and that is the fault.

**Procedure.** The root-cause skill.
