---
name: corral-handoff
description: "Preserve decisions and open work when handing off a long or delegated task."
---

Record the current objective, accepted decisions, immutable artifact versions or target tree, selected resources and verification criteria.
List completed work with evidence and remaining work with its owner. Preserve unresolved user questions, pending approvals, cancellation state and uncertain effects.
Never transfer credentials, execution permits or an approval as reusable natural-language authorization. A checkpoint cannot undo external calls, deployment or cost.
Identify the exact next action and the checks needed before resuming. Do not replay an uncertain external effect or silently treat an interrupted execution as successful.
Keep the handoff concise and private where it contains user content or local context.
