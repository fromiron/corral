Remote hosts

Connect to a Corral server through a host in your SSH config. Projects and credentials stay on that host.

    Add or reconnect a host

    Paste the link printed by the remote Corral server. It remains valid until that server stops and is not saved.

    Use key authentication with a previously verified host key. The Corral and preview ports must be free locally. Files and runs belong to the remote host. Disconnecting does not stop remote runs.
