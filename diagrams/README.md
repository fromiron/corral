# 도식

`spec-1.mmd`: 검토 루프의 개념 흐름. Loop completed는 설명용 상태이지 다섯 번째 노드가 아니다.

`technical-1.mmd`: Studio/API/Coordinator/GraphRunner/Pi/DB 책임과 통신.

`technical-2.mmd`: Run의 주요 상태 전이. crash→interrupted는 본문 규칙에 별도 설명.

`reins.mmd`: 지시 접수와 실제 요청 전달, 산출물 연결을 구별하는 시퀀스.

모두 Mermaid 소스다. 제품 그래프 정의 JSON과 동일 형식이 아니며, 실행 엔진의 입력으로 사용할 수 없다.
