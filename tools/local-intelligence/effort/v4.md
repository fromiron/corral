# effort-v4

배포 가중치 `effort-v4`(`packages/local-intelligence/weights/effort-v4.json`)와 추론 판정 모델 `Corral Effort Judge 270M`의 구성과 평가 요약이다. 판정 규칙은 [로컬 AI 명세](../../../docs/specs/features/local-intelligence.md#자동-추론-판정-judged-정책-corral-effort-v4)가 정한다.

## 추론 판정 모델

| 항목 | 값 |
|---|---|
| 기반 모델 | `google/embeddinggemma-2` 텍스트 인코더(270M), Apache-2.0 |
| 미세조정 | 인코더와 수준 판정층을 함께 학습하고 토큰 임베딩은 고정 |
| 변환 | litert-torch 0.11.0. 단일 키 헤드 주의층은 질의 헤드를 묶어 계산해야 값이 맞는다 |
| 양자화 | ai-edge-quantizer 0.10.0 `dynamic_wi8_afp32`(인코더), 토큰 임베딩은 채널별 int8 |
| 번들 | litert-lm-builder 0.19.0. 토큰 임베딩 그래프, 128·256·512·1,024토큰 인코더 그래프, 기반 모델의 SentencePiece 토크나이저, 시작 토큰 2와 끝 토큰 1 |
| 파일 | `corral-effort-judge-270m-int8.litertlm`, 305,148,992바이트, sha256 `628e232e9949748b9f8e6b255bc09855a265d98893e2dc733f13fb1eb60c5314` |
| 입력 | `task: classification \| query: ` 뒤에 `effort-text-v2`, 1,024토큰에서 앞부분을 남기고 자른다 |

## 판정층

- 수준 판정층: LayerNorm(768) → 768→64 GELU → 4. 위 미세조정에서 인코더와 함께 학습했다.
- 열림 판정층: 미세조정한 인코더의 고정 임베딩에 학습한 로지스틱 회귀다. 라벨 기준은 [라벨 기준표](label-rubric.md#열린-요청과-닫힌-요청)를 따른다.
- 상향 기준 0.55는 학습 자료의 그룹 교차검증으로 골랐다. 골드 행은 쓰지 않았다.
- 보류 기준은 0이라 판정을 보류하지 않는다.

## 회귀 수치

아래 세트들은 이전 후보 선택에 이미 쓰였으므로 독립 최종 평가가 아니라 회귀 자료다. 모두 배포 정밀도(int8 번들, LiteRT-LM 0.19 런타임)로 판정했다. 과제 세트의 성공과 토큰은 수준별로 미리 실행해 둔 기록에서 판정한 수준의 결과를 읽은 값이다.

| 세트 | 결과 |
|---|---|
| 어려운 과제 24개 | 13/24 성공, 16.7M 토큰 |
| 쉬운 과제 최종 | 328/331 성공, 과제당 평균 1,398 토큰 |
| 골드 조정용, LLM 상향 라벨 기준 | 정밀도 0.47, 재현율 0.77 |
| 골드 최종용, LLM 상향 라벨 기준 | 정밀도 0.67, 재현율 0.71, P(open)의 AUC 0.901 |
| 지연(6스레드 CPU, 1,024토큰 그래프) | 중앙값 441 ms, p95 1,033 ms |

## 한계

- 열린 요청 규칙은 어려운 과제와 쉬운 과제 세트에서 한 번도 발동하지 않았다. 두 세트가 모두 닫힌 수정이므로 열린 요청의 실제 실행 결과는 별도 검증이 필요하다.
- 골드 라벨은 LLM이 붙였고 골드 최종용은 여러 번 열렸다. 독립 최종 평가에는 새 골드 기록이 필요하다.
- 학습 텍스트의 도구 상태는 `success`/`error`였고 제품은 `completed`/`failed`/`pending`을 쓴다. 이 차이가 판정에 주는 영향은 재지 않았다.
- 라벨의 치우침은 [라벨 기준표](label-rubric.md#알려진-치우침)에 있다.
