addressee gates. Its synthetic agreement is insufficient for promotion. Preserve

## Data and estimands

AMI's intended-addressee annotations cover too few unexposed teams for another
F/C/P/H experiment. Human adjacency-pair annotations support a separate
**observed-response selection** proxy. A later linked response can supply a
target participant but never text, names, roles, or other model input.
Nonresponders are not automatically forbidden participants. Multiple recorded
responders can be eligible alternatives for a single reply. The absence of a
response does not establish an explicit silence label.

Inventory relation types and temporal validity before freezing new team-level
F/C/P/H partitions. Exclude the eight exposed teams. Prefer ten fresh H teams
and distinct calibration/policy teams when the inventory supports them. Keep
whole original scenes and all derived views together. Explicit all/none
instructions require compatible supervision; do not force a next-speaker label
to override that product rule.

The new natural view aggregates already-completed dialogue acts into
chronological speaker turns before keeping the last twelve. Preserve
constituent IDs and timestamps for leakage checks. Do not invent display names
that are missing from metadata. The first experiment's twelve-act view remains
unchanged and is reported as a different input representation.

Keep original synthetic F for multilingual product-specific instructions and
explicit one/set/all/none/exclusion behavior. Fresh controlled evaluation must
contain independently authored conversations and grouped variants, not rewrites
of the exposed oracle. Any new LLM teacher or reviewer still uses explicit high
or higher; do not import unverified generated reasoning traces.

## Comparisons before new H

Use F development groups to compare:

1. Unchanged native EG2 with a learned shared candidate scorer over current
   message, role/history similarities, and observable speaker recency.
2. Qwen3.5 0.8B short-answer SFT with the new data. Compare the original timeline
   view with an explicit participant-to-past-turn index derived from visible
   history; it must contain no semantic labels or future relations.
3. Qwen3.5 2B using the same data/view only if measured artifact and resident
   memory requirements fit the original limits. Larger size is a challenger,
   not an explanation for the first failure.

The existing joint/span and pair encoders remain reusable alternatives if the
cheap scorer or generative models expose a concrete representational gap. Avoid
an unbounded architecture sweep. Keep the existing shared-weight option and
measure task interference on F; separate roles are allowed when sharing harms
one task.

Freeze exact models, input versions, calibration, action policies, and strongest
P references before new H. Report observed-response prediction, normative
controlled dispatch, and old addressee regression separately. Retain the
original +5pp/group-confidence/exclusion/resource gates and disclose any
population where a gate is not evaluable. No failed candidate becomes a default.

The related [Speak or Stay Silent study](https://arxiv.org/abs/2603.11409)
examines participant-specific intervention decisions and supports testing
task-specific supervision. Its binary participation metric and generated
reasoning traces are not interchangeable with Corral's recipient-set task or
verified training labels.
