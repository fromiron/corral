# CR-040: 설정의 적용 범위와 저장 책임 정리

- 상태: 승인 — Bell, 2026-10-19, 검토 결과의 순서대로 구현 요청.
- 기준: `eb630cf`; CR-023의 설정 프레임과 CR-022의 불변 revision·신뢰 계약 유지.
- 추적: C-086, CRL-UX-004, TC-UX-004-H/N 및 기존 TC-HAR-004-H, TC-HAR-016-H.
- 디자인: 내장 leeskills design-workflow, review-components, review-visuals,
  check-accessibility, verify-changes. 기존 토큰·Button·Select·Dialog 재사용.

## 변경 순서와 계약

1. 개인 기본 작업 방식은 에이전트 구성의 독립 화면, 프로젝트 기본 작업 방식은
   프로젝트의 독립 화면으로 분리한다. 선택 후 저장/취소를 제공한다. 기존
   `/settings/harness#project-defaults`는 프로젝트 기본값 화면으로 안내한다.
   작업 방식 편집기는 프로필 revision만 저장한다. 기본값 변경은 각 기본값 화면이 맡는다.
2. 스킬·확장은 라이브러리 관리, MCP는 프로젝트 서버 등록·인증·연결 시험을 맡는다.
   연결 버튼은 작업 방식 편집기로 이동한다. 리소스·MCP 서버·허용 도구 선택과
   스킬 버전 교체는 편집기 초안에 모으고 저장 시 한 번 publish한다.
   CR-023 §7의 화면 내 연결 편집을 이 탐색 경로로 대체한다.
3. 데이터 폴더 전환은 실행 유무와 무관하게 전환을 확인한 뒤 수행한다.
   취소하면 서버와 데이터 위치가 유지된다. 폴더 보기와 전환 동작을 시각적으로 나눈다.
4. 프로젝트 폴더 메뉴는 폴더·도구 범위를 표시한다. 프로젝트 미선택 화면의
   제목·안내·선택 경로를 통일하고 동일 페이지 링크와 중복 선택기를 없앤다.
5. 모델은 프로필 → 인증 관리 → 서버 공통 자동 추론 순서로 배치한다.
   연결된 인증의 재로그인/로그아웃 경로는 유지한다. 앱 정보에 버전·데이터 위치를
   표시하고, 단축키는 적용 범위로 묶는다. 단순 설정 행/편집기/라이브러리의
   역할을 유지하면서 본문 폭·헤딩·버튼·선택 상자를 공용 패턴으로 맞춘다.

## 반례와 필요한 검증

- 정상: 기본값 메뉴가 편집기를 거치지 않고 선택기를 보여주며 메뉴 하나만 활성화된다.
  개인과 프로젝트 저장의 API 대상을 분리하고 작업 복귀 URL을 보존한다.
- 실패: 조회/저장 충돌에서 초안과 오류를 보존한다. 기존 revision·신뢰 검사 유지.
- 취소: 기본값 초안 취소, 편집 이탈 취소, 데이터 폴더 전환 취소는 저장/중단하지 않는다.
- 중복: 저장 중 중복 조작을 막고 기존 publish operation ID 재시도 규칙을 유지한다.
- 늦은 응답: 프로젝트 전환 후 이전 조회/저장 결과가 새 대상 화면을 덮지 않는다.
- 기존 E2E를 수정해 스킬 교체·MCP 선택의 최종 동작을 유지한다. 새 E2E는 기본값
  범위/저장/취소에 집중한다. 데스크톱 전환 확인은 격리한 Electron/fixture로 검증한다.
- 넓은/좁은 화면, 키보드, 오류/빈 상태와 관련 설정·세션 복귀 회귀를 확인한다.
  유료 모델·실사용 데이터 폴더 전환은 사용하지 않는다.

## 범위 밖

새 저장소·스키마·의존성·프로필 상속 규칙·실행 스냅샷 변경 없음.
PR/push/merge와 전체 릴리스 판정은 이번 요청에 포함하지 않는다.

## 구현·검증 기록

각 단계에서 실패 증거와 통과 결과를 기록한다.

### 1. 기본값 화면 분리

- 실패: 기존 hash URL이 독립 경로로 이동하지 않아 새 범위 E2E 실패 확인.
- 통과: 기본값 선택/취소/명시 저장/409 초안 보존/이탈 취소/작업 복귀,
  기존 스킬 관리·실행 회귀 총 3 E2E. Studio typecheck와 production build 통과.
- 프로필 저장은 기본값을 함께 바꾸지 않으며, 기존 고정 revision은 유지한다.

### 2. 작업 방식 연결 저장 통합

- 실패: 스킬/MCP 연결 동작이 편집기로 이동하는 링크가 아니어서 기존 E2E 수정본 2개 실패.
- 통과: 스킬 버전 교체 확인/취소/필수 모드 유지, 저장 전 revision 불변,
  MCP 인증·discovery·선택·저장·고정 revision 실행까지 4 E2E와 선택 유틸리티 단위 시험.
- 라이브러리의 공용 프로필/기본값 publish 경로와 중복 대상 선택기를 제거했다.
  MCP 연결·취소·신뢰/인증 검사는 기존 McpConnection을 재사용한다.
