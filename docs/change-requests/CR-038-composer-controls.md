# CR-038: 컴포저 조작과 독립 모델 선택

- 상태: **구현 승인** — Bell, 2026-10-19 UI 개선 및 첨부안 전체 범위 요청.
- 기준: `3236759`, C-119, CRL-COMPOSER-001, TC-COMPOSER-001-H/N.
- 현재 브랜치는 모델/노력을 하나의 Select에 섞고 있다. main 기준 제안의 별도 Select 설명 대신 실제 작업 코드에서 출발한다.

`@` 옆에 첨부·템플릿 실행 메뉴를 둔다. 파일 input은 메뉴 밖에 계속 마운트하고 기존 MIME/크기/개수/정규화/중복 규칙을 재사용한다. 같은 템플릿을 다시 실행하면 매 실행에 한 번 삽입한다. 기존 intent 잠금/초안 저장 경로를 거친다. 파일 선택 취소·재선택·제거를 유지하고 오래된 읽기는 다른 세션이나 교체된 초안에 붙이지 않는다.

첨부는 새 요청에서만 전송한다. 질문/대기열/지시에서는 제외함을 표시하되 초안에 보존하며 이 이유만으로 해당 전송을 막지 않는다. 사용하지 않은 첨부는 메시지를 보낸 뒤에도 남긴다. 기존 CR-027의 모든 모드 전송 차단 규칙은 이 명시적 변경으로 대체한다. 실행 방식/검토만/검증 범위는 유지하며 slash 첨부 명령이나 형식은 늘리지 않는다.

모델 메뉴는 모델 라디오 그룹과 별도 추론 노력 하위 메뉴를 사용한다. 모델만 바꾸면 노력값을 보존하고 노력만 바꾸면 모델을 보존한다. 미지원 값도 유지·표시하고 새 요청만 차단한다. 명시 기본/유효 값 선택으로 해소하며 질문 모드에는 노력 표시/차단을 적용하지 않는다. 일반 노력과 Ultra의 최대 지원 정책은 구분하고 팀 역할/Ultra pool을 단일 칩으로 덮어쓰지 않는다.

저장은 한 번에 하나만 허용한다. 동기 lock과 저장 상태로 연속 변경 및 직후 전송을 막고 성공 후 확정된 전체 선택을 사용한다. 실패/revision 충돌을 표시하며 저장 전 값을 완료처럼 표시하지 않는다. 다른 세션으로 이동한 후 응답은 현재 세션 상태를 덮어쓰지 않는다.

자동 추론 설정은 현재 Corral 서버 작업공간 전체에 적용됨을 설명한다. 새 Run에서 자동을 선택한 역할에만 적용되며 이미 실행 중인 Run과 고정 설정은 바꾸지 않는지 실제 snapshot 경로를 확인한다. 프로젝트별 스위치는 추가하지 않는다.

대표 브라우저 반례는 메뉴 실행/재실행·파일 선택 후 메뉴 닫힘·초안 보존·미지원 조합·저장 중 전송/실패·질문 왕복·키보드/좁은 화면이다. 기존 API payload와 회귀를 우선 확장하고 문구 전용 테스트는 추가하지 않는다.
