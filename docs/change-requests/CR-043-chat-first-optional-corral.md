# CR-043: 바로 대화하는 기본 UX와 선택적 Corral

- 승인: 2026-10-21, 사용자가 구현 후 셀프리뷰·실사용을 거쳐 복잡한 UX를 개선하고 Corral 제작·적용을 선택 사항으로 두도록 요청했다.
- 범위: 기존 기본 대화, 프로젝트 시작 안내, 입력창의 옵션 노출과 접근성. 실행 정책이나 권한을 확대하지 않는다.
- 관련 계약: CR-024 auto 세션, CR-040 기본 작업 방식, CR-041 채팅 위젯, CR-042 추가 기능.

## 사용자 흐름

1. 새 대화를 열면 요청을 바로 작성할 수 있다. 사용자 Corral·템플릿·목적·제목·폴더 설정을 먼저 요구하지 않는다.
2. 연결된 모델이 없으면 입력한 내용을 보존하고 같은 화면에서 모델 연결로 안내한다. 폴더가 필요한 작업에는 기존 연결·신뢰·관리 사본 절차를 사용한다.
3. 기본 입력창에는 요청, 첨부·참조, 모델, 권한, 음성, 보내기를 둔다. 실행 중 중지·대상 선택과 필요한 오류·승인은 계속 해당 맥락에서 표시한다.
4. `요청 옵션`에서 선택적 Corral, 작업 스타일, 품질·검증 범위, 역할별 설정, 프로젝트 자료와 요청 템플릿을 고른다. 선택한 Corral 및 비기본 옵션은 닫아도 요약해 전송 결과를 예측할 수 있게 한다.
5. 처음에는 입력창과 시작 안내를 가까이 배치한다. 메시지가 생기면 기존 대화 흐름과 하단 입력창을 유지한다.
6. 새 프로젝트는 대화 목록부터 연다. 명시한 Corral 라이브러리 링크·저장한 탭·편집기·D&D·Reins는 계속 접근할 수 있다.

## 보존하는 계약

- 기본 세션은 `corralId: null`과 기존 auto 시작 → Coordinator → Run 경로다. 새로운 실행 엔진이나 숨은 테스트 입구를 만들지 않는다.
- 명시한 Corral이 삭제되면 자동으로 다른 방식으로 바꾸지 않는다. 사용자가 복구 방식을 고르며 초안을 보존한다.
- 모델·Corral 저장의 revision, 불확실한 전송의 원래 command ID, 권한·예산·파일 소유권, 큐의 원래 설정을 보존한다.
- 옵션을 숨겼다고 설정값을 초기화하거나 기본 권한을 높이지 않는다. 실행 중인 Run에는 새 입력창 설정을 소급하지 않는다.
- 모델 이름과 명시한 추론 선택은 알아볼 수 있게 표시한다. 설정되지 않은 추론의 내부 설명은 상시 칩에서 제거하고 모델 메뉴 안에서 확인하게 한다.
- 옵션은 키보드로 열고 닫을 수 있어야 하며 Escape 뒤 트리거로 초점이 돌아온다. 390px에서도 입력·전송·복구와 선택 요약이 잘리면 안 된다.

## 발견한 역전

`AUTHORITY INVERSION`: CR-024와 현재 사용자 요청은 Corral 없는 시작을 허용하지만, 기존 빈 프로젝트의 기본 팀 탭과 시작 안내의 Corral 생성 단계는 제작을 선행 조건처럼 제시했다. 해당 기본 흐름을 바로잡고 기존 제작 기능은 선택적 경로로 보존한다.

## 검증

`CRL-UX-005` / `C-137` / `TC-UX-005-H`, `TC-UX-005-N`.

- 변경 전 실제 UI에서 팀 탭 기본과 상시 고급 선택을 실패로 확인한다.
- 빈 실제 서버 작업 공간에서 사용자 Corral 생성 없이 새 대화 → 요청 → Coordinator 결과 → 재로드 이력을 확인한다.
- Corral 선택·해제, 고급 옵션 요약·초안 복원·전송 snapshot, 삭제된 Corral의 명시 복구를 확인한다.
- 기존 모델·권한·첨부·큐·Ultra·작업 스타일 및 편집기 회귀의 실제 UI 경로를 유지한다.
- 인앱 브라우저의 같은 화면 전후, 좁은 화면과 키보드 흐름을 확인한다. 로컬 테스트 모델의 응답은 외부 모델 품질 증거로 취급하지 않는다.

## 참고의 범위

PI Desktop 로컬 소스, T3 Code와 ChatGPT·Claude Desktop의 공식 안내에서 기본 메시지 입력과 선택적 설정 노출을 참고한다. 다른 제품의 권한 기본값이나 실행 의미를 복제하지 않으며, 참고 제품을 직접 사용하지 않은 부분은 문서·소스 관찰로 구분한다.
