# CR-014: Corral 데스크톱 Workbench

- 상태: 승인 — Bell, 2026-10-17, 계획 확정 후 "구현해".
- 기준: Corral `da3799c`.
- 관련: CR-009–013, 제품 스펙 §4, ADR-026. 진행과 증거는 [구현 추적](../evaluation/Desktop-Workbench.md).

## 요구

1. 프로젝트·세션 탐색, 대화, 하단 입력창, 작업 패널, 메뉴·스크롤·포커스 동작을 Corral 데이터에 연결한다.
2. 세션 하나가 대화 하나다. 사용자 요청은 SessionEntry, 새 실행은 Run, 실행 내 활동은 Execution이다. 지시·대기는 별도 Run처럼 표시하지 않는다. 여러 에이전트·결과를 합쳐 하나의 가짜 답변을 만들지 않는다.
3. 공통 앱 프레임, 프로젝트별 세션 목록·검색·고정·보관·메뉴, 시스템/라이트/다크 테마, 한국어/영어, 명령 팔레트와 설정을 제공한다. 팀 캔버스·실행 상세·결과·비교·데모도 같은 프레임을 쓴다.
4. 입력창은 하단에 고정한다. 세션별 초안, 자동 높이, Ctrl/⌘+Enter, IME 보호, 대기 항목 편집, 동일 command ID 재시도를 유지한다. 파일 참조는 상대 경로와 줄 범위를 요청에 넣으며 에이전트 권한을 추가하지 않는다.
5. 파일·변경·산출물·검증 작업 패널은 탭·확대·닫기와 세션별 복원을 지원한다. 새 이벤트로 사용자의 선택을 빼앗지 않는다. 파일 탐색·읽기는 연결된 원본 또는 세션 복사본으로 제한하고 기존 경로·symlink·크기 정책을 재사용한다.
6. diff는 Pierre의 공개 API로 구문 강조·통합/나란히·접힌 구간·줄 선택·의견을 표시한다. 비교 tree·쪽·줄·인용에 고정된 의견, 승인 tree 반영, 충돌과 되돌리기 보호는 CR-013을 따른다.
7. Electron Linux x64 AppImage를 제공한다. Node 24.19와 서버·SQLite native module·Pi/ONNX worker를 동봉한다. Node/pnpm이 없는 환경에서 실행되어야 한다. Git과 사용자 검증 도구는 별도 설치 상태를 안내한다.
8. renderer는 Node/파일 시스템에 직접 접근하지 않는다. 제한된 DesktopBridge(창, 폴더 선택, 파일 위치, 외부 링크, 앱 정보), 기존 loopback REST/SSE와 세션/CSRF 경계를 사용한다.
9. 중복 실행 방지, 창·화면 복원, 시작 실패·재연결, 실행 중 종료 확인을 제공한다. 기존 workspace를 명시적으로 열 수 있고 자동 이동·덮어쓰기는 없다. 중단한 Run의 자동 재개는 없다.

### Pierre와 CSP

Pierre 1.5.2는 shadow DOM의 테마 style 요소와 token별 style 속성을 생성하며 공개 nonce API를 제공하지 않는다. 실제 서버 E2E에서 기존 `style-src 'self'`가 이를 차단했다. Studio의 CSS에만 `style-src 'self' 'unsafe-inline'`을 허용한다. `script-src 'self'`, `default-src 'none'`, 외부 연결·이미지·폰트 제한, HTML 산출물의 별도 opaque sandbox는 유지한다. 본문은 여전히 React 텍스트/SafeMarkdown으로 렌더링하며 사용자 HTML을 앱 DOM에 삽입하지 않는다. 서버 E2E는 CSP 오류가 없는 구문 강조와 기존 의견·승인·반영·되돌리기를 함께 검증한다.

## 제외

Windows/macOS 배포, 터미널, 직접 코드 편집, Git commit/push UI, 원격 환경, 플러그인 마켓, 자동 업데이트, 백그라운드 상주, crash resume. D&D·협업·Reins는 제외하지 않는다.
