# CR-044: 작업을 유지하는 설정과 Composer 정돈

- 승인: 2026-10-21, Bell이 검토된 1–6단계 구현·단계별 검증·셀프리뷰·커밋을 요청했다.
- 기준: `ab3a103`; CR-040 설정 범위, CR-041 위젯, CR-043 기본 대화 계약을 보존한다.
- 추적: CRL-UX-006 / C-140 / TC-UX-006-H,N. 결정: ADR-037.
- 구현: C-140 완료. [검증 기록](../evaluation/Contextual-Settings-UI-2026-10-21.md); 1–6단계 완료 계획은 Git 이력으로 관리한다.

## 승인된 변경

1. 작업 화면에서 설정은 작업 라우트를 마운트한 채 모달로 연다. 기존 `/settings`와 하위 직접 링크는 독립 화면으로 유지하며 같은 콘텐츠를 사용한다. 선택한 범주만 마운트한다.
2. 설정 전용 검색값만 추가/제거한다. 작업의 Run/result/artifact/execution·패널·hash를 보존한다. 열기는 push, 내부 전환은 replace, 직접 진입/새로고침의 닫기는 replace한다. 소유한 이전 히스토리를 확인할 때만 back한다. URL은 권한의 근거가 아니다.
3. 모든 이탈은 같은 미저장 보호를 거친다. 저장 후 이동/버리기/계속 편집을 제공하고 실패·검증 오류는 머문다. 명시적 신뢰/복원/채택/삭제 등은 자동 저장에 포함하지 않는다.
4. 저장 중 닫기는 허용한다. 제출 시 대상·revision·명령 식별자를 고정하고 결과 책임은 폼보다 오래 유지한다. 중복 쓰기는 막고 최신 편집을 오래된 응답으로 지우지 않는다. 응답 유실은 실제 값/기존 receipt로 재확인하며 새 ID로 무조건 재실행하지 않는다. CAS 없는 API의 다른 클라이언트 간 순서는 보장한다고 주장하지 않는다.
5. 비밀 입력은 URL/history/일반 초안·로그에 저장하지 않는다. 닫으면 정리하며 실패 후 재입력을 요구한다. 조회/저장의 늦은 응답은 다른 대상 화면을 바꾸지 않는다.
6. 모달은 기존 Dialog·Menu·Select를 사용한다. 포커스 복귀, 중첩 Escape, 배경 단축키 차단, IME·좁은 화면·확대·기존 테마를 보존한다. 실행·승인 수명은 모달과 독립적이고 새 승인으로 포커스를 빼앗지 않는다.
7. Composer는 기존 상태·모델 메뉴·컨텍스트 상세를 재사용한다. 알약은 실제 데이터와 정확한 대상만 표시한다. CR-041의 compact 진입 표시를 알약으로 정돈하되 Todo 본문·실행 요약·승인/실패 조치·Reins를 제거하지 않는다. 새 SSE/계측 API를 추가하지 않는다.
8. 현재 실행과 다음 요청 모델을 구분한다. 0/미확인/부분 데이터/미지원 및 컨텍스트·Run 누적 사용량·계정 한도를 혼동하지 않는다. 짧은 상세는 기존 팝오버를 우선한다.

## 설정별 범위와 적용

| 범주 | 원본/대상 | 반영 시점·보존 경계 |
|---|---|---|
| 일반·단축키 | 이 기기의 preferences | 즉시. 데이터 폴더 전환은 별도 명시 확인 |
| 모델·인증·이미지·추론 | 현재 서버의 모델/인증 설정 | 저장 이후 요청. 기존 Run snapshot 유지; 모델 설정→키→갱신의 부분 성공 보존 |
| 작업 방식 | 선택한 profile의 불변 revision | 명시 publish. 기본값은 별도 저장 |
| 개인 기본값 | 현재 서버의 personal/default | 이후 요청 |
| 프로젝트 기본값·폴더·도구·MCP | 명시한 projectId | 해당 프로젝트의 이후 요청; 신뢰·검사·인증은 기존 명시 동작 |
| 스킬·확장 | 현재 서버의 리소스/패키지 | 불변 revision·명시 연결/채택. 실행 중 snapshot 불변 |
| 금고 | 현재 서버의 선택 도메인 | preview·명시 확인·적용 journal. 일반 저장으로 자동 복원 금지 |
| 앱 정보 | 현재 연결의 메타데이터 | 읽기 전용 |

프로젝트가 없으면 선택을 요구하며 최근 프로젝트로 자동 대체하지 않는다. 서버/대상 삭제·권한 해제·연결 실패는 오류와 재조회 경로로 표현한다.

## 검증 계약

- H: 작업 초안/첨부/그래프/스크롤/선택 대상 유지; 독립 URL 호환; 저장/닫기/포커스 복귀; 실제 상태/다음 요청 표시.
- N: 모든 닫기/범주·대상 이동/뒤로가기, 중첩 Escape, 실패/취소/중복/늦은 응답/응답 유실/추가 편집, 비밀값 정리, SSE 중복 없음, 승인 유지, IME와 배경 단축키, 390px/200%/한·영/테마.
- 기존 settings-scope/models/desktop-workbench/chat-widgets/harness/vault/skill-quality 시험을 확장한다. 새 테스트는 구현 전 실패를 확인한다.
- Linux Chromium/Firefox/실제 화면의 결과와 native IME·Windows/macOS·스크린리더 미검증을 구분한다. 유료 공급자 호출 없이 기존 deterministic fixture로 실행 계약을 확인한다.

## 범위 밖

새 라우터·상태관리·DB migration·전역 모달 프레임워크, 계정 한도/가격 API, 새 Activity Rail, 모델별 effort 기억, 일본어 locale 추가. D&D·Reins·권한·예산·실행 정책을 바꾸지 않는다.
