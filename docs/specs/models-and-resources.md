# 모델·추론·리소스

연결 방법·프로필 설정·호환 엔드포인트·컨텍스트의 상세 사용 계약은 [모델 안내](../guides/models.md)에서 관리한다. 이 문서는 경계와 관련 자료를 연결하며 모델 목록이나 설정 필드 전체를 복제하지 않는다.

## 연결과 요청 설정

실제 연결은 사용자가 완료한다. 카탈로그에 모델이 있다는 것, credential이 설정되었다는 것, 특정 capability가 검증되었다는 것, 실제 외부 요청이 성공했다는 것을 구분한다. 키를 계획·채팅·Corral 정의·이벤트·공개 export에 넣지 않는다.

프로필 설정과 실제 Run snapshot을 구분한다. 저장 revision·적용 scope를 확인하고 변경을 실행 중인 Run에 소급하지 않는다. 추론 판정의 관찰과 요청 적용은 구분한다. 프로필·엔드포인트를 편집하는 동안 불완전한 초안은 로컬 스키마 검증을 통과할 때까지 유효값 미리보기 요청을 보내지 않는다. 명시적인 저장의 서버 검증과 revision 경계는 유지한다.

판정 전용 API(TypeSafe Jev, OpenAI Decisions)의 연결, 키 보관, 전송 범위, 기록은 [판정 API](features/decision-apis.md)가 정한다. 모델 로그인과 모델 공급자 키는 판정 API에 쓰지 않는다.

컴포저의 모델 칩은 현재 선택을 보여 주며 디자인킷 ModelPicker 팝업 한 곳에서 실제 프로필 목록과 해당 모델의 추론 선택지를 함께 제공한다. 모델을 선택해도 팝업을 유지해 추론을 이어서 고를 수 있다. 저장된 프로필이 없어졌거나 요청한 추론 수준이 지원되지 않아도 다른 값으로 대체하지 않고 현재 값을 비활성 선택지로 보인다. 저장 중에는 이미 열린 팝업의 모델·추론 선택도 변경할 수 없다. 추론 선택의 legacy·provider default·고정 수준·자동·요청별 모드는 기존 요청 계약을 유지한다. 설명 요청처럼 추론을 선택하지 않는 문맥에서는 추론 설정을 노출하지 않는다. 근거가 없는 속도·품질·비용 점수와 별도의 웹 검색 토글은 표시하지 않는다. 팝업은 컴포저의 스크롤 영역에 잘리지 않으며 키보드 이동·선택·Escape 닫기와 트리거로의 포커스 복귀를 지원한다.

ModelPicker는 원본의 모델 목록·짧은 설정행·조건부 가로 노력 탭·하단 설명 구성을 유지한다. 추론 설정행은 기존 정책과 실제 지원 수준을 고르는 하나의 짧은 선택 제어이며, 고정 수준을 선택한 경우에만 노력 탭이 펼쳐진다. unset을 추론 끄기로 해석하거나 고정 모드를 고르는 과정에서 임의 수준으로 바꾸지 않는다. 지원 수준이 많으면 가로 탭 안에서 이동할 수 있고 팝업 너비를 넘지 않는다. 모델 목록이 없는 브라우저 데모는 시뮬레이션 상태를 같은 칩과 빈 목록 안내로 표시하며, 내부 모의 프로필을 연결된 실제 모델로 표시하지 않는다.

공급자 SDK의 일반 지원과 Corral에서 검증한 인증·도구·추론 매핑은 같지 않다. 새 연결을 추가할 때 어댑터·취소·usage·compatibility 시험을 확인한다. 샘플 모델명이나 과거 조사표를 최신 지원 목록으로 복제하지 않는다.

## Ultra 제거

Ultra(복수 모델 협업·후보 비교·후보 경쟁)는 제거됐다. 새 요청은 Ultra를 고를 수 없고 이전 Ultra Run은 열리지 않는다. 모델 프로필의 최고 추론 단계 메타데이터와 일반 추론 설정은 유지하며, 미연결 모델·확인되지 않은 추론 매핑을 임의 fallback으로 숨기지 않는다.

## 내장팩·Skill·확장

`apps/server/resources/builtin/`는 개발 조사 문서가 아니라 제품 리소스다. 설치, 신뢰, 바인딩, 본문 전달, 실제 수행과 평가 통과는 서로 다른 상태다. 리소스 선택 자체는 native 코드 실행이나 권한 확대의 허가가 아니다.

내장 design Skill의 [NOTICE](../../apps/server/resources/builtin/design/NOTICE.md)는 고정 upstream과 복사 범위를 기록한다. 이 고지와 LICENSE를 문서 정리 대상으로 제거하지 않는다. 업데이트·rollback은 기존 버전·hash·신뢰 경계를 보존한다.

## 의존성과 출처

설치 버전은 각 package.json과 pnpm-lock, 검사 입력은 [dependency lock](../dependency-lock.json)을 확인한다. 과거 외부 제품·버전 조사는 기본 읽기 경로가 아니다.

실제 차용물 고지는 [THIRD-PARTY-NOTICES](../../THIRD-PARTY-NOTICES)에 유지한다. 외형이 바뀌었다는 이유만으로 코드·본문의 차용 관계가 사라졌다고 판단하지 않는다.

## 실패 안내와 연결 확인

실행 실패는 저장된 안전한 공급자 분류와 HTTP 상태를 사용해 인증, 요청 한도, 공급자 오류, 연결 실패를 구분한다. 원문 공급자 응답이나 자격 증명을 노출하지 않는다. 이미지 입력 능력이 확인되지 않은 모델의 거절은 미연결로 안내하지 않으며 이미지 제거 또는 이미지 지원 모델 선택으로 연결한다. 모델 선택·설정에서 확인된 이미지 입력 여부를 표시한다.

설정의 연결 확인 동작과 경계는 [모델 엔드포인트 연결 확인](features/model-connection-check.md)을 따른다.
