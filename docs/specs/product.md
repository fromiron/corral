# 제품 범위와 기본 흐름

Corral은 로컬 우선 AI 작업 도구다. 일반 사용자는 대화에서 요청을 시작하며, 직접 만든 Corral과 D&D 편집기는 선택적인 제작 경로다. Reins는 실행 중 대상과 적용 시점을 확인하며 개입하는 경로로 유지한다.

## 현재 승인 계약

새 대화를 열 때 Corral·템플릿·목적·제목·작업 폴더를 선행 조건으로 요구하지 않는다. 모델이 없으면 작성한 요청을 보존하고 모델 연결을 안내한다. 폴더가 필요한 작업에는 기존 연결·신뢰·관리 사본 절차가 적용된다.

프로젝트는 관련 세션·자료의 범위이고, 세션은 대화와 실행 이력의 연속성이다. 사용자 요청, Run, 역할의 실행 시도, 모델 turn을 같은 단위로 취급하지 않는다. 과거 결과 질문과 새 실행은 기존 결과를 덮어쓰지 않는다.

명시한 Corral이 삭제된 경우 다른 팀으로 조용히 대체하지 않는다. 사용자가 복구 방식을 고르며 초안을 보존한다. 기본 대화가 가능하다는 이유로 D&D·협업·Loop·Reins 계약을 제거하지 않는다.

## 제품 경계

공개 demo의 모의 실행을 실제 LLM처럼 표시하지 않는다. 모델의 내부 추론 전체가 아니라 관측 가능한 요청·응답·도구·작업·승인·설정 기록을 보여 준다. 멀티에이전트가 항상 더 싸거나 정확하다고 가정하지 않는다.

브라우저 재접속, 기록 재열람, 체크포인트에서 새 Run 시작과 죽은 프로세스의 효과 자동 재실행은 다른 기능이다. 역사 자료의 초기 제외 목록만으로 현재 기능을 거절하거나, 후속 승인을 근거로 미구현 경계를 제거하지 않는다.

실행 경계는 [실행과 안전](execution-and-safety.md), UI 세부는 [Workbench](workbench.md)를 따른다. 그래프·Reins·예산의 상세 규칙은 [제품 상세 계약](product-contract.md)의 필요한 절만 참조한다.
