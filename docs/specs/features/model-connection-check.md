# 기능 명세: 모델 엔드포인트 연결 확인

- 상태: implemented
- 비목표: 추론 실행, 모델 사용권·비용 검증, 내장 공급자 API 검사, 자동 재시도.

## 사용자 관측 동작

설정 → 모델의 등록된 OpenAI 호환 접속 주소에는 연결 확인 버튼이 있다. 설정됨은 자격 증명 준비 여부이며 연결 성공을 뜻하지 않는다. 버튼은 모델 목록 주소만 확인하고 마지막 결과 범주와 확인 시각을 보여준다. 실패는 인증, 요청 제한, 서버 오류, 연결 실패, redirect, 검사 미지원으로 구분하고 다음 행동을 안내한다.

## 계약

[API 계약](../api-contract.md)의 revision을 현재 설정과 비교한다. URL은 요청 본문으로 받지 않는다. 현재 등록된 base URL의 `/models`에 GET을 보내며 origin에 바인딩된 키만 사용하고 redirect를 따라가지 않는다. 키가 필요한데 없거나 origin이 다르면 외부 요청 없이 인증 실패로 답한다. 5초 이내에 연결을 끝내며 본문은 보관하지 않는다. 응답은 범주, HTTP 상태 또는 null, 확인 시각만 포함한다.

결과는 서버 메모리에만 저장한다. 설정 또는 자격 증명이 바뀌면 이전 결과를 지우며 진행 중인 이전 검사의 늦은 결과도 반영하지 않는다. 화면은 검사 중 버튼을 비활성화한다. 연결 성공은 모델 추론 성공을 보장하지 않는다.

## 수용 시나리오

- 현재 설정과 origin이 일치하면 인증 정보를 사용한 GET 한 번으로 접속 여부를 확인한다. 모델 호출은 발생하지 않는다.
- 오래된 revision은 요청 전에 거절한다. 다른 origin에 저장한 키는 보내지 않는다.
- redirect 응답은 확인 결과로 표시하되 이동하지 않는다. 공급자 본문과 키는 결과에 포함하지 않는다.
- 검사 도중 키가 바뀌면 이전 응답은 폐기하고 새 검사를 요구한다.
- 서버가 중단되면 연결 실패와 주소·네트워크·로컬 서버 확인 안내를 표시한다.
- 서버 재시작 뒤에는 마지막 확인 결과가 없다. 사용자가 다시 확인할 수 있다.

## 보안·성능·접근성

기존 설정 인증·CSRF 경계를 사용한다. 새로운 목적지나 redirect를 허용하지 않는다. 검사는 모델 추론을 수행하지 않고 5초로 제한된다. 버튼은 기존 디자인 키트를 사용하며 검사 결과는 status 영역에서 읽을 수 있다.
