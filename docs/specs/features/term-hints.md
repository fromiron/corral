# 기능 명세: 용어 설명

- 상태: accepted
- 비목표: 일반 낱말과 상태 낱말의 설명, 문장 속 낱말의 밑줄이나 링크, 용어 사전 화면, 처음 사용 안내

## 사용자 관측 동작

제품이 지은 이름은 낱말만으로 뜻을 알 수 없다. 그런 이름은 화면에서 이름으로 서는 자리에서 뜻을 한 문장으로 알 수 있다. 대상 용어와 그 자리는 [용어집](../glossary.md)의 "설명이 붙는 용어" 표가 정한다.

설명은 두 형태 가운데 하나로 붙는다.

- **이름 뒤의 정보 아이콘.** 용어가 제목이나 이름표인 자리에 쓴다. 이름 바로 뒤에 정보 아이콘 버튼이 하나 선다. 포인터를 올리거나, 키보드 포커스를 주거나, 누르면 설명이 열린다. 포인터를 설명 위로 옮겨도 닫히지 않는다. 포인터를 올려 연 설명은 포인터가 아이콘과 설명을 떠나면 닫히고, 포커스나 누르기로 연 설명은 포커스가 아이콘과 설명을 떠나면 닫힌다. 포커스가 남아 있는 동안에는 포인터가 지나가도 닫히지 않는다. 어느 경우든 Escape를 누르거나 바깥을 누르면 닫힌다. 설명이 열려 있어도 Tab과 Shift+Tab은 설명이 없을 때와 같은 컨트롤로 간다.
- **컨트롤의 툴팁.** 용어가 컨트롤의 이름인 자리(도구 줄의 버튼과 선택기, 보기 탭)에 쓴다. 그 컨트롤에 포인터를 올리거나 포커스를 주면 툴팁이 이름과 그 아래 같은 한 문장을 보인다. 컨트롤이 툴팁으로 상태를 함께 말하고 있었다면 상태는 이름 줄에 남는다. 아이콘을 더하지 않는다.

설명의 내용과 모양은 두 형태가 같다. 용어의 이름과 뜻 한 문장이 킷 툴팁과 같은 면 위에 선다. 뜻은 그 용어가 무엇이고 무엇에 쓰는지를 말하며, 조작 방법이나 화면의 다른 정보를 되풀이하지 않는다.

한 화면에서 한 용어의 설명 자리는 한 곳이다. 창이 여럿인 화면에서는 창마다 따로 센다(대화 창과 그 옆에 연 실행 기록 창은 저마다 자리를 가진다). 문장 속 낱말, 버튼의 글자, 상태 낱말, 목록의 각 행, 메뉴의 항목에는 붙이지 않는다. 이름 옆에 뜻을 말하는 글이 이미 보이는 자리(편집기 팔레트의 단계 설명 등)에도 붙이지 않는다.

아이콘은 이름과 같은 줄에 서고 그 줄의 높이를 바꾸지 않는다. 설명이 열리고 닫혀도 주변 항목은 움직이지 않는다([대화 입력 흐름](composer-flow.md)의 튐 없는 본문과 같은 기준이다).

## 계약

- 용어의 이름과 뜻은 메시지 `Terms.<id>.name`과 `Terms.<id>.meaning`에 있고 두 언어가 같은 키를 가진다. 화면은 이 메시지를 읽는 공용 컴포넌트로만 설명을 그린다. 자리마다 뜻을 따로 쓰지 않는다.
- 정보 아이콘 버튼의 접근 이름은 `Terms.about`이 만드는 "<이름> 설명"이다. 뜻 문장은 설명이 닫혀 있어도 버튼의 설명으로 낭독기에 읽힌다.
- 컨트롤의 툴팁 형태는 그 컨트롤의 접근 이름을 바꾸지 않는다. 뜻 문장은 컨트롤의 설명으로 붙는다.
- 설명은 명령을 내지 않고 저장되는 상태를 바꾸지 않는다.

## 수용 시나리오

```gherkin
Given 용어가 제목인 자리에 정보 아이콘이 있다
When 아이콘에 포인터를 올린다
Then 용어의 이름과 뜻 한 문장이 뜬다
And 주변 항목의 위치는 변하지 않는다

Given 같은 아이콘에 키보드 포커스가 있다
When Escape를 누른다
Then 설명이 닫히고 포커스는 아이콘에 남는다

Given 키보드 포커스로 설명을 열었다
When 포인터가 아이콘 위를 지나간 뒤 Tab을 누른다
Then 포커스는 설명이 없을 때와 같은 다음 컨트롤로 가고 설명이 닫힌다

Given 터치 화면에서 같은 아이콘을 본다
When 아이콘을 누른다
Then 설명이 열리고, 바깥을 누르면 닫힌다

Given 용어가 도구 줄 컨트롤의 이름이다
When 그 컨트롤에 포인터를 올리거나 포커스를 준다
Then 툴팁이 이름 아래에 뜻 한 문장을 보인다
And 그 컨트롤 옆에 정보 아이콘은 없다

Given 한 화면에 같은 용어가 여러 번 나온다
Then 그 용어의 설명 자리는 한 곳뿐이다

Given 대화 창의 활동 바를 펼쳤고 옆 창에 실행 기록의 Reins 영역이 열려 있다
Then Reins의 설명 아이콘은 창마다 하나씩 있다

Given 화면 언어를 바꾼다
Then 이름과 뜻이 그 언어의 메시지로 바뀐다
```

## 보안·성능·접근성

- 설명은 정적 메시지만 싣는다. 사용자 본문, 경로, 키가 들어가지 않는다.
- 아이콘 버튼의 누르는 영역은 24px 이상이다. 아이콘의 색은 보조 글자색 토큰을 쓰고, 포커스 표시는 킷의 것을 쓴다.
- 열리고 닫히는 움직임은 킷의 팝업 움직임을 따르고 reduced motion에서는 움직이지 않는다.
- 설명은 열릴 때만 그려진다. 닫힌 설명 때문에 목록이나 타임라인이 다시 계산되지 않는다.
