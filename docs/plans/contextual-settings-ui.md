# 문맥형 설정 UI 실행 계획

승인: [CR-044](../change-requests/CR-044-contextual-settings-ui.md), 기준 `ab3a103`. 계약은 CR과 [Workbench](../current/workbench.md)에 두며 이 문서는 잔여 실행 순서만 추적한다.

| 단계 | 상태 | 완료 조건 |
|---|---|---|
| 1 계약·범위 | 완료 | CR/요구/태스크/테스트/ADR 연결, spec 검사 |
| 2 콘텐츠 분리 | 완료 | 기존 설정 URL·폼·저장 payload 호환, 모델 조회의 라우트 의존 제거 |
| 3 저장·이탈 | 대기 | 대상 고정·pending 결과·dirty·secret·충돌/유실 처리와 반례 |
| 4 모달 | 대기 | 단일 Outlet·URL/history·포커스/단축키·초안/구독 보존 |
| 5 Composer | 대기 | 기존 위젯·메뉴 재사용, 정확한 대상과 상태·스크롤 유지 |
| 6 마감·통합 | 대기 | 실제 화면·관련 회귀·타입/문서 검사, 증거와 상태 갱신 |

각 단계는 실패 테스트 → 구현 → 관련 검증 → 셀프리뷰·보강 → 커밋 순서다. 구현 완료한 계획은 필요한 계약·증거를 회수한 뒤 삭제하며 Git 이력으로 관리한다. Windows/macOS 실기는 별도 검증 대상으로 유지한다.
