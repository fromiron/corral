# H6 다섯 비교군 로컬 SDK 검증

2026-10-18, Linux / Node 24.19.0 / Pi 1.3.0. 소스 `15a933c8a3faaf0b496a9ef45703c899f9c7807e`의 깨끗한 작업 트리에서 실행했다. 실제 Pi SDK, Coordinator, SQLite, 파일 broker, 검증 프로세스를 사용하고 모델 응답만 고정된 로컬 provider로 제공했다. 외부 계정과 유료 모델 호출은 없다.

각 비교군은 같은 Git commit의 새 작업 사본에서 calibration과 holdout을 각각 실행했다. 고정 정답은 2+2=4와 3+4=7이다. 총 10개 실행 모두 성공했고 최종 JSON 및 실제 파일 내용이 정답과 일치했다.

| 비교군 | 통과 | 실행당 모델 요청 | 수정 회차 | 확인한 경로 |
|---|---:|---:|---:|---|
| 기본 | 2/2 | 5 | 0 | read_file → write_file → 산출물 제출 |
| 필수 스킬 | 2/2 | 5 | 0 | 요청에 필수 본문이 전달됨 |
| 결정적 검사 | 2/2 | 6 | 0 | 등록 검사 프로세스 실행 및 pass |
| 검토·수정 | 2/2 | 19 | 1 | 잘못된 후보 → 검사 fail → 검토 반려 → 수정 → pass |
| Pi 코딩 도구 | 2/2 | 5 | 0 | Pi read/edit 계약을 Corral broker로 실행 |

필수 스킬 본문 전달은 2회, 완료된 검사는 6회다. 모든 실행에 정의·하네스 해시, 사용량, 실제 도구 실행, 정답 판정이 남았다. 최종 판정의 잘못된 통과와 불필요한 반려는 0건이었다. 검토·수정의 첫 실패는 의도적으로 만든 입력이다.

이 실험은 실행 경로와 평가 계측의 통합 검증이다. 모델 응답과 정답이 고정돼 있으므로 실제 LLM 정확도, 비용 절감, 일반적인 성능 개선을 측정한 결과가 아니다. calibration/holdout 분리도 평가 기능의 동작 확인이며 통계적 일반화를 뜻하지 않는다.

상세 결과는 [JSON](Personal-Harness-Local-Fixture-Results.json), 재현 명령은 [실행 안내](../../tools/evaluation/README.md)에 있다. 테스트는 `packages/cli/test/harness-comparison.test.ts`가 같은 fixture를 실행해 10개 결과와 작업 사본·검사·스킬 증거를 검증한다.
