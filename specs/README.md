# 기능 명세와 초기 증거

현재 작업의 출발점은 [문서 지도](../docs/README.md)다. 이 디렉터리의 모든 파일을 기본 컨텍스트로 읽지 않는다.

| 문서 | 역할 |
|---|---|
| [헌장](constitution.md) | 제품 비협상 항목·상태 의미·변경 절차. 후속 승인 범위는 현재 제품 계약과 연결 |
| [Canvas](001-canvas/spec.md), [Reins](reins/spec.md), [출시](009-demo-release/spec.md) | 기능별 상세 수용 기준 |
| [P0–P9 증거](001-canvas/evidence/) | 각 commit·환경의 초기 실행 기록. 현재 작업 지시·현재 후보 통과 선언이 아님 |

초기 Canvas 계획·태스크표와 First Run 계획은 작업 트리에서 삭제하고 Git 이력으로 관리한다. 현재 태스크 원장은 [backlog](../contracts/backlog.json), 남은 일은 [상태표](../docs/status.md)다.
