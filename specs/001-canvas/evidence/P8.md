# P8 증거 기록 — 보안과 외부 입력

- 기록일: 2026-10-15 (Asia/Tokyo)
- 범위: C-042, C-043, C-044, C-045
- 환경: 초기 구현 Node 24.14.0, 리뷰 수정·최종 검증 Node 24.19.0, pnpm 10.30.3, Linux x64. 외부 유료 호출 없는 로컬 검증.
- 최종 후보의 통합 검증: `CORRAL_PYTHON=/tmp/corral-release-python/bin/python pnpm release:gate`. 결과는 `test-results/release/evidence.json`에 source hash와 단계별 완료 시각으로 기록된다.
- 상태 `implemented`는 로컬 구현·검증을 뜻한다. `done`/hosted CI 성공을 주장하지 않는다.

- same-origin session·CSRF token·Host/DNS-rebinding 경계와 요청 크기/빈도/동시 연결 제한을 적용했다. 오류에는 raw request·provider secret·local path를 반사하지 않는다.
- SQLite에 등록한 documentId/sourceId만 문서 도구가 받는다. HTTPS 읽기는 IPv4/IPv6와 모든 DNS 응답·redirect를 검사하고 검증한 주소로 연결을 고정한다. TLS 검증, MIME/1 MiB/timeout/취소를 적용한다. HTML·압축 응답은 거절한다.
- 기본 corpus 검색은 외부 key가 필요 없다. Brave는 live Run, 명시적 provider 선택, 서버 opt-in, backend key와 유한 request cap을 모두 요구한다. 일반 CI에서 호출하지 않는다.
- `pnpm corral validate/dev/run/inspect/export`가 동일한 server Coordinator를 사용한다. `--demo`, `--input`, `--watch`, exact approval ID/revision과 SIGINT/SIGTERM 취소를 제공한다. inspect/export는 DB를 읽기 전용으로 연다.

주요 검증: `apps/server/test/server.test.ts`, `safe-http.test.ts`, `inputs.test.ts`, `sse.test.ts`, `packages/cli/test/cli.test.ts`, Pi 허용 도구 테스트.

RED 확인: CSRF 누락, 취소 전 DNS/request 실행, 저장한 모델·도구 응답 조회 404, raw provider 오류 노출, CLI 미구현. 실제 Node CLI process의 SIGINT는 DB에 cancelled를 저장한 뒤 exit 130으로 끝났다.

새 외부 의존성은 추가하지 않았다. Context7 MCP가 현재 세션에 노출되지 않아 기존 설치 버전의 source/types와 표준 Node API를 사용했다. Brave나 실제 LLM 호출은 이 변경 검증에서 실행하지 않았다.

셀프 리뷰 수정·실제 앱 조작·현재 검증 경계는 [통합 수정 근거](review-fixes.md)를 따른다.
