## 4. 브라우저에서 발견해 고친 결함

1. 노드 본문(`position: relative`)이 왼쪽 핸들을 덮어 연결 드롭이 가로채졌다(Playwright 진단). 핸들을 본문 뒤에 렌더링하도록 바꿨다.
2. "Add" 버튼이 새 노드를 Loop 영역 위에 놓았다. 기존 노드의 오른쪽에 놓도록 바꿨다.
3. 미완성 초안에서 `controlEdges: Too small…` 같은 schema 문구가 그대로 보였다. 흔한 경우를 평이한 문장과 위치로 바꿨다.
4. 제어 연결 라벨이 핸들 포트 라벨과 겹쳐 중복 표시됐다. 제어 연결 라벨을 없앴다.
5. P1 테스트 작성 중: Playwright의 한 번에 이동하는 `dragTo`로는 React Flow 노드가 움직이지 않는다. E2E는 단계적 포인터 이동을 쓴다.

## 5. 아직 하지 않은 것

- GitHub Actions 실행, Firefox E2E.
- `/settings/models`(C-058, P3), `/demo`(C-046, P9).
- 캔버스 이동·확대(viewport)는 저장하지 않는다. 자동 저장도 없다(명시적 저장과 이탈 경고만).
- Loop·Decision의 실행(P2 GraphRunner, P5 검토 루프). 현재는 검증·저장·내보내기만 되고 실행 버튼은 이유와 함께 비활성.
- Run 기록 보존(P2 서버). 새로고침하면 브라우저 runtime의 Run은 사라지고 Run 페이지가 그 사실을 표시한다.
- 진단 메시지의 세부 문구(compiler의 영어 문장)는 일부만 카탈로그로 옮겼다. 다국어 지원 때 code별로 정리한다.
